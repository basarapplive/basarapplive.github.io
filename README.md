# BasarApp - Shared Living OS

Welcome to the official repository for the BasarApp landing page, hosted at [basarapplive.github.io](https://basarapplive.github.io).

BasarApp is the ultimate Mess & Shared Living OS, designed to streamline and automate day-to-day coordination for roommates and shared households.

## Key Features

- **Meal Tracking**: Log daily meal schedules and counts effortlessly.
- **Expense & Bill Splitting**: Calculate shared utility bills, rent, and other collective costs with transparency.
- **Grocery Management**: Coordinate shared grocery lists and keep track of individual contributions.
- **Interactive Simulator**: Experience how the mobile application operates directly from the landing page.
- **Multi-language Support**: Seamless toggle between English and Bangla editions.

## Technical Details

This landing page is built using:
- **React** & **TypeScript**
- **Tailwind CSS** for responsive, modern UI styling
- **Three.js** (WebGL) for a fluid, interactive particle background
- **Vite** as the fast frontend build tool
